## 二、最终方案确定

### 2.1 方案名称

**分层语言引导规划与物理验证（Hierarchical Language-Guided Planning with Physical Verification, HLGP-PV）**

### 2.2 核心组件

1. **LLM任务分解器**：将自然语言指令分解为子任务序列
2. **运动原语库**：预定义+学习的运动原语
3. **参数优化器**：梯度优化原语参数
4. **轨迹生成器**：生成关节轨迹
5. **物理验证器**：验证轨迹可行性
6. **双循环机制**：反馈和重规划

### 2.3 创新点

1. **分层LLM规划**：首次将LLM用于分层任务分解
2. **物理验证反馈**：首次在LLM规划中引入物理验证
3. **运动原语参数化**：可优化的参数化原语
4. **双循环收敛**：有理论保证的收敛机制
