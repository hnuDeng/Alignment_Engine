## 一、对"分层"这一核心假设的质疑

### 1.1 问题：分层是否真的必要？

**质疑：** 当前方案的核心假设是"分层规划比端到端规划更好"。这个假设是否成立？

**反面证据：**
1. **DreamerV3成功案例**：单一模型在150+任务上超越专用方法，无需分层
2. **端到端学习趋势**：深度学习的趋势是端到端，减少人工设计
3. **信息损失**：分层可能导致信息损失

**正面证据：**
1. **人类认知**：人类确实使用分层思维
2. **复杂任务**：复杂任务确实需要分解
3. **可解释性**：分层提高了可解释性

**关键问题：**
- 分层的收益是否大于成本？
- 在什么情况下分层更好？
- 在什么情况下端到端更好？

### 1.2 问题：LLM分解是否优于规则分解？

**质疑：** 当前方案使用LLM分解任务，但规则分解可能更可靠。

**对比分析：**

| 维度 | LLM分解 | 规则分解 |
|------|---------|----------|
| 灵活性 | 高 | 低 |
| 可靠性 | 中 | 高 |
| 泛化能力 | 高 | 低 |
| 可解释性 | 中 | 高 |
| 计算开销 | 高 | 低 |

**关键问题：**
- LLM分解的准确性如何保证？
- 规则分解是否足够覆盖常见任务？
- 是否可以结合两者？

### 1.3 问题：运动原语库是否必要？

**质疑：** 当前方案依赖运动原语库，但直接生成轨迹可能更灵活。

**对比分析：**

| 维度 | 运动原语库 | 直接生成 |
|------|------------|----------|
| 灵活性 | 低 | 高 |
| 可靠性 | 高 | 低 |
| 泛化能力 | 中 | 高 |
| 计算开销 | 低 | 高 |

**关键问题：**
- 原语库的覆盖度如何保证？
- 直接生成是否可行？
- 是否可以结合两者？

## 二、对"双循环验证"的质疑

### 2.1 问题：双循环是否一定收敛？

**质疑：** 双循环验证假设通过反馈可以改进规划，但可能不收敛。

**反例：**
1. **任务不可行**：任务本身不可行，无论怎么重规划都失败
2. **反馈不准确**：验证器反馈不准确，导致错误重规划
3. **局部最优**：陷入局部最优，无法跳出

**关键问题：**
- 如何检测不收敛？
- 如何处理不收敛的情况？
- 最大迭代次数如何设置？

### 2.2 问题：物理验证器是否准确？

**质疑：** 物理验证器可能不准确，导致误判。

**问题来源：**
1. **仿真与现实差距**：仿真验证不等于真实验证
2. **模型不准确**：物理模型可能不准确
3. **计算误差**：数值计算可能有误差

**关键问题：**
- 如何保证验证器的准确性？
- 如何处理验证器的误判？
- 是否需要多重验证？

### 2.3 问题：反馈信息是否有用？

**质疑：** 验证器的反馈信息可能不足以指导重规划。

**问题：**
1. **反馈太笼统**：只说"失败"，不说为什么
2. **反馈不具体**：无法定位具体问题
3. **反馈不准确**：反馈可能误导

**关键问题：**
- 如何设计有用的反馈？
- 如何保证反馈的准确性？
- 如何利用反馈进行重规划？

## 三、对"LLM能力"的根本质疑

### 3.1 问题：LLM是否真的理解物理？

**质疑：** LLM可能只是记忆了物理规律，而不是真正理解。

**证据：**
1. **定量预测不足**：LLM无法给出精确数值
2. **分布外失败**：LLM在新场景中可能失败
3. **幻觉问题**：LLM可能产生不存在的物体

**关键问题：**
- LLM的物理理解深度如何？
- LLM在什么情况下会失败？
- 如何弥补LLM的不足？

### 3.2 问题：LLM分解的边界条件

**质疑：** LLM在什么情况下会分解失败？

**失败场景：**
1. **模糊指令**：指令不清晰
2. **复杂场景**：场景太复杂
3. **新任务**：任务在训练分布外
4. **多义性**：指令有多种理解

**关键问题：**
- 如何检测LLM分解失败？
- 如何处理分解失败？
- 是否需要回退机制？

### 3.3 问题：LLM的可解释性

**质疑：** LLM的决策过程不透明，难以解释。

**问题：**
1. **黑箱**：LLM是黑箱模型
2. **不可控**：无法控制LLM的输出
3. **不一致**：LLM的输出可能不一致

**关键问题：**
- 如何提高LLM的可解释性？
- 如何保证LLM的输出一致？
- 如何控制LLM的输出？
