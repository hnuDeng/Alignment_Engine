## 一、实验设计的核心原则

### 1.1 科学性原则

**可复现性：**
- 实验必须可复现
- 代码和数据公开
- 随机种子固定

**对照性：**
- 必须有Baseline对照
- 控制变量
- 公平比较

**统计显著性：**
- 足够的样本量
- 统计检验
- 置信区间

### 1.2 实用性原则

**真实性：**
- 任务要真实
- 环境要真实
- 评估要真实

**可操作性：**
- 实验可操作
- 指标可测量
- 结果可解释

## 二、实验任务设计

### 2.1 任务层次设计

**Level 1：原子任务**
- pick：抓取物体
- place：放置物体
- move：移动到位置

**Level 2：组合任务**
- pick_and_place：抓取并放置
- stack：堆叠物体
- pour：倒液体

**Level 3：复杂任务**
- set_table：摆桌子
- make_coffee：做咖啡
- clean_up：收拾桌面

### 2.2 任务变体设计

**物体变体：**
- 不同形状：立方体、圆柱、球
- 不同大小：小、中、大
- 不同材质：刚性、柔性

**场景变体：**
- 不同布局：稀疏、密集
- 不同障碍：无障碍、有障碍
- 不同桌面：平的、斜的

**指令变体：**
- 不同表述：同一任务不同说法
- 不同粒度：粗粒度、细粒度
- 不同模糊度：清晰、模糊

### 2.3 任务难度分级

**简单任务（30%）：**
- 单步操作
- 少量物体
- 静态环境
- 清晰指令

**中等任务（40%）：**
- 2-3步操作
- 多个物体
- 简单动态
- 一般指令

**复杂任务（30%）：**
- 4+步操作
- 大量物体
- 复杂动态
- 模糊指令

## 四、评估指标设计

### 4.1 主要指标

**任务成功率：**
```
SR = 成功任务数 / 总任务数
```
- 最重要的指标
- 直接反映系统能力

**规划时间：**
```
PT = 从接收指令到生成轨迹的时间
```
- 反映系统效率
- 影响用户体验

### 4.2 次要指标

**迭代次数：**
```
IT = 双循环的平均迭代次数
```
- 反映收敛性
- 影响计算开销

**物理可行性：**
```
PF = 可行轨迹数 / 总轨迹数
```
- 反映安全性
- 影响部署可行性

**泛化成功率：**
```
GS = 新任务成功数 / 新任务数
```
- 反映泛化能力
- 影响长期价值

### 4.3 辅助指标

**可解释性评分：**
```
ES = 人工评估规划的可理解性（1-5分）
```

**安全性评分：**
```
SF = 安全检查通过率
```

**用户满意度：**
```
US = 用户评估满意度（1-5分）
```

## 五、实验流程设计

### 5.1 Phase 1：单元测试（1周）

**目标：** 验证每个组件的正确性

**测试内容：**
1. LLM分解模块
2. 原语选择模块
3. 参数优化模块
4. 轨迹生成模块
5. 物理验证模块

**成功标准：**
- 每个模块通过单元测试
- 错误率 < 5%

### 5.2 Phase 2：集成测试（1周）

**目标：** 验证系统的集成功能

**测试内容：**
1. 完整流程测试
2. 错误处理测试
3. 边界条件测试

**成功标准：**
- 完整流程通过测试
- 错误处理正确

### 5.3 Phase 3：简单任务测试（1周）

**目标：** 在简单任务上验证系统

**测试内容：**
1. 10个简单任务
2. 每个任务10次试验
3. 记录所有指标

**成功标准：**
- 任务成功率 > 80%
- 规划时间 < 10秒

### 5.4 Phase 4：中等任务测试（2周）

**目标：** 在中等任务上验证系统

**测试内容：**
1. 10个中等任务
2. 每个任务10次试验
3. 与Baseline对比

**成功标准：**
- 任务成功率 > 60%
- 不低于Baseline

### 5.5 Phase 5：复杂任务测试（2周）

**目标：** 在复杂任务上验证系统

**测试内容：**
1. 10个复杂任务
2. 每个任务10次试验
3. 与Baseline对比

**成功标准：**
- 任务成功率 > 40%
- 优于Baseline

### 5.6 Phase 6：泛化测试（1周）

**目标：** 验证泛化能力

**测试内容：**
1. 新物体测试
2. 新场景测试
3. 新指令测试

**成功标准：**
- 泛化成功率 > 50%

### 5.7 Phase 7：消融实验（1周）

**目标：** 验证各组件贡献

**测试内容：**
1. 去掉LLM分解
2. 去掉物理验证
3. 去掉双循环
4. 去掉参数优化

**成功标准：**
- 每个组件都有正贡献

## 六、统计分析设计

### 6.1 样本量计算

**公式：**
```
n = (Z_α/2 + Z_β)^2 * 2σ^2 / Δ^2
```

**参数设置：**
- α = 0.05（显著性水平）
- β = 0.2（检验效能）
- σ = 0.3（标准差估计）
- Δ = 0.2（最小可检测差异）

**计算结果：**
- n ≈ 50（每个条件）

### 6.2 统计检验

**成功率比较：**
- 使用卡方检验
- 或Fisher精确检验

**规划时间比较：**
- 使用t检验
- 或Mann-Whitney U检验

**多重比较校正：**
- 使用Bonferroni校正
- 或FDR校正

### 6.3 置信区间

**Bootstrap置信区间：**
- 重采样1000次
- 计算95%置信区间

### 8.1 实验设计要点

1. **任务设计**：3个层次，多种变体
2. **Baseline设计**：3个必选，2个可选
