## 一、系统级失败模式

### 1.1 失败模式1：LLM理解失败

**症状：**
- LLM输出格式错误
- LLM输出内容不合理
- LLM产生幻觉

**原因：**
- 指令模糊
- 场景复杂
- LLM能力不足

**检测方法：**
```python
def detect_llm_failure(llm_output):
    # 检查格式
    if not is_valid_json(llm_output):
        return "格式错误"
    
    # 检查内容
    if not is_reasonable(llm_output):
        return "内容不合理"
    
    # 检查幻觉
    if has_hallucination(llm_output):
        return "产生幻觉"
    
    return None
```

**应对策略：**
1. **重试**：重新调用LLM
2. **简化指令**：简化输入指令
3. **回退**：回退到规则分解

### 1.2 失败模式2：原语选择失败

**症状：**
- 没有合适的原语
- 原语参数不合理
- 原语组合失败

**原因：**
- 原语库覆盖不足
- 参数空间不匹配
- 组合逻辑错误

**检测方法：**
```python
def detect_primitive_failure(primitive, task):
    # 检查原语是否存在
    if primitive not in primitive_library:
        return "原语不存在"
    
    # 检查参数是否合理
    if not are_params_reasonable(primitive.params):

    if not check_preconditions(primitive, task):
        return "前置条件不满足"
```

**应对策略：**
1. **学习新原语**：从示范中学习
2. **组合原语**：组合现有原语
3. **直接生成**：跳过原语，直接优化

**症状：**
- 优化不收敛
- 陷入局部最优
- 超出计算预算

**原因：**

- 学习率不合适
- 约束太严格

**检测方法：**

**应对策略：**
1. **多起点优化**：使用多个初始点
2. **调整学习率**：使用自适应学习率
3. **放松约束**：放松部分约束

## 二、组件级失败模式

### 2.1 LLM组件失败

**失败类型：**
1. **API调用失败**：网络问题、API限流
2. **输出格式错误**：JSON解析失败
3. **内容不合理**：输出与任务无关
4. **幻觉**：编造不存在的物体

**处理代码：**
```python
class RobustLLM:
    def generate(self, prompt, max_retries=3):
        for attempt in range(max_retries):
            try:
                response = self.llm.generate(prompt)
                
                # 验证输出
                if self.validate_output(response):
                    return response
                else:
                    print(f"输出验证失败，重试 {attempt + 1}")
            
            except APIError as e:
                print(f"API错误: {e}，重试 {attempt + 1}")
            
            except Exception as e:
                print(f"未知错误: {e}，重试 {attempt + 1}")
        
        # 所有重试失败，使用回退方案
        return self.fallback(prompt)
    
    def fallback(self, prompt):
        # 使用规则分解作为回退
        return self.rule_based_decompose(prompt)
```

### 2.2 优化器组件失败

**失败类型：**
1. **数值溢出**：梯度爆炸
2. **不收敛**：优化不收敛
3. **局部最优**：陷入局部最优

**处理代码：**

```python
class RobustOptimizer:
    def optimize(self, objective, initial_params, max_retries=3):
        for attempt in range(max_retries):
            try:
                # 使用不同初始点
                params = self.random_initialize() if attempt > 0 else initial_params
                
                # 优化
                result = self.optimizer.optimize(objective, params)
                
                # 验证结果
                if self.validate_result(result):
                    return result
                else:
                    print(f"结果验证失败，重试 {attempt + 1}")
            
            except NumericalError as e:
                print(f"数值错误: {e}，重试 {attempt + 1}")
            
            except Exception as e:
                print(f"未知错误: {e}，重试 {attempt + 1}")
        
        # 所有重试失败，使用简单方案
        return self.simple_solution(initial_params)
```

### 2.3 验证器组件失败

**失败类型：**
1. **误判**：可行轨迹被拒绝
2. **漏判**：不可行轨迹被接受
3. **计算错误**：验证计算错误

**处理代码：**
```python
class RobustVerifier:
    def verify(self, trajectory, num_verifiers=3):
        results = []
        
        # 使用多个验证器
        for i in range(num_verifiers):
            try:
                result = self.verifiers[i].verify(trajectory)
                results.append(result)
            except Exception as e:
                print(f"验证器 {i} 错误: {e}")
        
        # 投票决策
        if len(results) == 0:
            # 所有验证器失败，保守决策
            return VerificationResult(passed=False, reason="验证器失败")
        
        # 多数投票
        passed_count = sum(1 for r in results if r.passed)
        return VerificationResult(
            passed=passed_count > len(results) / 2,
            reason=f"投票结果: {passed_count}/{len(results)}"
        )
```
