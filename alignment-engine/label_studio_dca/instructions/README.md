# Label Studio 数据为中心AI工作流 - 实现指令

## 项目概述

基于Label Studio进行二次开发，实现数据为中心AI（Data-Centric AI）工作流，包括：
- Active Learning Engine（主动学习引擎）
- Data Quality Assessment（数据质量评估）
- Data Drift Detection（数据漂移检测）

## 指令文件列表

1. `01_project_setup.md` - 项目环境搭建
2. `02_active_learning_backend.md` - 主动学习后端模块
3. `03_active_learning_strategies.md` - 主动学习策略实现
4. `04_data_quality_backend.md` - 数据质量评估后端
5. `05_data_quality_assessors.md` - 数据质量评估器实现
6. `06_drift_detection_backend.md` - 漂移检测后端
7. `07_drift_detectors.md` - 漂移检测器实现
8. `08_api_integration.md` - API集成和路由
9. `09_frontend_base.md` - 前端基础架构
10. `10_frontend_active_learning.md` - 主动学习前端界面
11. `11_frontend_data_quality.md` - 数据质量前端界面
12. `12_frontend_drift_detection.md` - 漂移检测前端界面
13. `13_testing.md` - 测试实现
14. `14_documentation.md` - 文档编写

## 使用说明

按照顺序执行每个指令文件中的任务。每个文件包含：
- 目标说明
- 需要创建/修改的文件列表
- 详细代码实现
- 验证检查点
